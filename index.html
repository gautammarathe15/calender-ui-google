CI/CD Scheduler & Pipeline Architecture

Cron: 0 6 * * * (Daily @ 06:00 AM IST)

Automated regression test execution flow configured via GitHub Actions / Jenkins. Below is the visual pipeline flow showing how automated triggers propagate through execution to reporting.

Step 1

Cron Trigger

Scheduled cron or webhook fires daily at 06:00 AM IST or manual push.

Step 2

Code Checkout

Pulls latest Playwright test scripts & configuration from repository.

Step 3

Environment Setup

Spins up Node.js runner container, installs browsers & dependencies.

Step 4

Test Execution

Runs headless Playwright test suite with date-mocking and API intercept.

Step 5

Report & Notify

Generates Allure/Extent reports and sends Slack/Email status alerts.

Sample GitHub Actions Workflow YAML

name: Daily Calendar Regression Scheduler
on:
  schedule:
    - cron: '30 0 * * *' # Runs daily at 06:00 AM IST
  workflow_dispatch:

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - name: Install Dependencies
        run: npm ci
      - name: Install Playwright Browsers
        run: npx playwright install --with-deps
      - name: Run Test Suite
        run: npx playwright test

Popup Validation (Logo, Amount, Date, Transaction ID) Verify company logo dimensions, currency/amount formatting, timestamp zones, and unique transaction ID alphanumeric patterns inside popups. Pass: All modal assets, numbers, and identifiers match backend logs.
Download Verification Trigger file downloads (PDF, CSV, Excel) and verify file extensions, non-corrupted content, and matching dashboard data. Pass: Files download successfully and contents match UI records.
